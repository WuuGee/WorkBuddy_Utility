# WorkBuddy v0.5.0 (Community Packs)

## New
- Community pet packs from `%LOCALAPPDATA%\WorkBuddy\Pets`.
- Custom colour theme from `%LOCALAPPDATA%\WorkBuddy\Themes\custom-theme.json`.
- Settings > Pet: **Open Custom Pets Folder** and **Open Custom Themes Folder** buttons with a packs summary.

## Install
Download `WorkBuddy-Setup-0.5.0.exe` and verify it against `docs/release/CHECKSUMS.md`.
The installer is not code-signed; SmartScreen may warn (More info > Run anyway).
