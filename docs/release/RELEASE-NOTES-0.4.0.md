# WorkBuddy v0.4.0 (AI Companion)

## New
- Optional local AI companion with Auto/Cpu/Gpu/Npu device preference (unavailable devices fall back to Cpu).
- **Ask Companion** tray item and a Settings > AI Companion page.
- The pet thinks and then speaks the reply.

## Install
Download `WorkBuddy-Setup-0.4.0.exe` and verify it against `docs/release/CHECKSUMS.md`.
The installer is not code-signed; SmartScreen may warn (More info > Run anyway).
